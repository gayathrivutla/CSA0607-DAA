CO1_AT1 – ShopSphere Scalability Audit

Overview

This project analyzes the time and space complexity of algorithms used in ShopSphere, an e-commerce platform. It evaluates algorithm efficiency using asymptotic notations, the Master Theorem, substitution method, and recursion trees to identify scalability issues and recommend improvements.

Repository Structure

CO1_AT1/
├── Question_1/
│   ├── Source_Code/
│   └── Report/
└── README.md

Contents

- Source_Code: Python implementation of the scalability audit.
- Report: Detailed solutions, mathematical derivations, complexity analysis, execution output, and screenshots.

Objective

To evaluate algorithm performance as the product catalogue grows and recommend efficient solutions for meeting processing requirements.

Technologies Used

- Python
- Design and Analysis of Algorithms
- Git and GitHub
